# Changelog

All notable changes to this project are documented in this file.

## v2.1.0-enhanced — 2026-09-07

First public release of **Shadow Eminence V2.1 Enhanced**.

### Added

- Enhanced six-pose idle loop with subtle breathing, a blink, and gentle attached cape movement.

### Preserved

- The other eight standard animations.
- All 16 validated look directions.

### Quality assurance

- Validated 1536×2288 PNG RGBA spritesheet.
- Codex V2 8×11 atlas layout.
- Zero magenta residues.
- Valid `pet.json` manifest.

### Compatibility

- Cursor and click reactions, plus aura effects, are intentionally not included because they are not supported by the compatible pet-state structure.
